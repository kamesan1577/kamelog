# ADR 0021: 公開画面のUIを再設計する

状態: 採用。2026-10-09の利用者の明示依頼に基づく。

## 依頼と範囲

利用者はUIをゼロから組み直し、Xに近い操作感、全機能、保存済みデータを維持するよう依頼した。元のNotionに近いデザイン言語を踏まえ、装飾を抑えた公開画面へ変更する。トップページのプロフィールは取捨選択してよい。デザインに関する検査の変更は認められているが、PRに変更箇所と理由を記載する。

## 変更

- 大きな角丸パネルで囲む配置を廃止し、本文と補助情報を余白と細い罫線で区切る。主色の墨色は維持する。
- ナビゲーションは216px、ヘッダーは56pxとする。1240px未満では右側の補助情報を隠し、本文内に検索とタグ絞り込みを表示する。タグは開閉式で、最初の5件から「もっと見る」で追加表示する。641〜900pxでは本文左右の余白を24pxにする。
- ホームではコンテンツ入口と人気投稿を経歴より先に表示する。紹介文を短くし、重複した作品一覧と関心の説明を省く。業務の取り組みは開閉できる。プロフィール設定と公開データファイルは変更しない。
- 投稿本文の行間、メタ情報のコントラスト、投稿操作の押しやすさを調整する。プロジェクトはサムネイル付きの横並びの行へ変更する。
- 日本語の見出しに負の字間を使わない。新たな広告コピー、実績、本人の主観は追加しない。文章はyomiyasuを参照して点検する。

## 維持するもの

API、DB、認証、媒体処理、バックアップ、連合機能、投稿・返信・下書きの状態管理は変更しない。ナビゲーション、検索、絞り込み、履歴、画像拡大、共有、モバイルのスクロール領域、未保存確認の既存操作を維持する。機能が参照するclass名とdata-ds属性も維持する。

## 検査の変更

- `tests/server/notion-polish.test.mjs`: 背景色の固定値を `#f6f5f4` から `#fbfbfa` へ変更する。他の状態・色・装飾禁止の検査は維持する。
- `tests/e2e/notion-polish.spec.ts`: bodyの背景色を上記へ変更し、プロフィールの塗り面を透明へ変更する。ボタンの44px、hover、見切れの検査は維持する。
- `tests/e2e/quiet-publication.spec.ts`: 320〜1440pxの検索・ナビゲーション・匿名操作境界、ホームの読順、プロフィールリンク、取り組みの開閉を追加する。
- `tests/e2e/journeys.spec.ts`: 既存の操作と検査を維持し、投稿・編集・詳細・vlogの確認箇所に永続保存する画面証跡を追加する。
- Storybookの画像差分は意図した変更と照合したうえで更新する。認証・データ・媒体・復元の検査を削除、skip、retryで回避しない。

## 実画面レビュー後の調整

CIの実ブラウザで59件のE2Eが成功した後、画面証跡を確認し、以下を修正した。

- vlogの時刻とキャプションを16:9動画の下に移動し、ネイティブ再生操作との重なりを解消する。再生・ループの処理は変えない。
- 投稿種別の選択直後やダイアログ表示直後の途中フレームを証跡にしない。フォント読込と表示状態を確認し、撮影時は有限アニメーションを完了させる。モバイルの内部スクロール領域も移動して、経歴・連絡先・アカウント下部・記事詳細を撮影する。
- 自動判定設定の状態文とエラー文の重なり、Fediverse案内見出しの末尾1文字だけの折返しを修正する。
- 投稿のタグと操作の余白を詰め、ホームのモバイル表示では重複する名前とラベルを省く。本文と44pxのモバイル操作領域は維持する。
- インライン投稿ボタンが既存の一般セレクタに負けて横に伸びる問題を、より限定したセレクタで修正する。本文入力の最小高は112pxから72pxへ変更する。

追加のデザイン検査変更:

- `SideNavigation.stories.tsx` の `FilledSelection`: 選択時を白字/墨色背景から墨色字/`rgb(229,229,223)`背景へ、選択hoverを`rgb(221,221,214)`へ変更。`aria-current`の切替、旧項目の解除、hover状態の検査は保持する。
- `tests/visual/design-system.spec.ts-snapshots/project-list-{mobile,tablet,desktop}-linux.png`: CIで描画された横並び一覧を個別に目視確認し、3枚の基準画像を更新する。実装の誤りを画像更新で隠すものではなく、上記の意図した一覧設計に合わせる。他の12枚は変更しない。
- vlogの16:9とキャプションの下配置、投稿ボタンの実際の幅、選択タブのコントラストを実ブラウザ検査に追加する。

StorybookのuserEventはDOMイベントを送るため、CSSの`:hover`の厳密な色検査はPlaywrightの実ポインター操作で行う。Storybookでは選択状態の切替と維持を、E2Eでは選択項目へのhoverと解除の両方を検査する。

## 記事操作の実DOM検査

実画面で記事の固定操作バーが見えない問題を確認した。既存CSSと既存E2Eの合成HTMLはMarkdownと操作をdetail-pageの直下に置いていたが、実画面は子divの中に置いていた。元のセレクタと合成HTMLの検査を残し、実際の子divにも同じsticky/fixed配置を適用する。実際に投稿した記事を開く既存journeyにも、操作バーの配置、共有ボタン、内部スクロール前後の表示領域の検査を追加する。機能の削除や画像基準の緩和で対処しない。

## 復元と検証の状態

この変更は消失した候補を、残っていたADR本文と変更内容の記録から再構成したもの。元の候補とのバイト単位の一致は未検証。以前の候補のテスト結果を、この再構成版の合格証跡として扱わない。再構成版に対する集約検査、ブラウザ操作、画像差分の確認は別途実行し、現在の確認結果をHANDOFFに記録する。
