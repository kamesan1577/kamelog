# ADR-0003: 承認済みUIを境界として保存する

状態: 採用

CSSと機能アイコン・DOMレイアウトを保持し、状態取得/変更処理だけをAPIへ接続する。
失敗応答で編集内容を破棄しない。公開表示に認証状態を楽観的に反映しない。
UIはCSS整合性チェックとPC/スマホE2Eで保護する。将来の正式なデザイン変更は明示承認を記録してbaselineを更新する。
ancebaseから採用するのは仕様/ADR/skills/CI/復元テストの役割分担であり、家系図ドメインや認証権限をコピーしない。
Issueは作業の追跡、リポジトリ内文書は仕様の正本。
