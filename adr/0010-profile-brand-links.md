# ADR-0010: 公開プロフィールの外部アカウントをブランドアイコンで表示する

状態: 採用

2026-09-10、利用者の明示依頼に基づき、公開プロフィールにあった `GitHub` の文字リンクをブランドアイコンのリンクへ変更し、X (`@kamesaniniad`) とQiita (`@kamesan1577`) を同じ場所へ追加する。

サービスの識別は各社のブランドアセットで行い、独自の類似ロゴは作らない。GitHubはGitHub Mark、Xは公式Xロゴ、QiitaはQiitaブランドアイコンを使用する。Qiitaは公式メディアキットの色・最小サイズ・アイソレーション・コントラスト・禁止例を守るため、`#55C500` のアイコンを `#3D4040` の背景上に18pxで表示し、36pxのタップ領域内に1/2幅・高さの余白を確保する。ロゴそのものへhover変形・影・回転を加えない。

既存の `app/notebook.tsx` の承認済み構造を大きく変更せず、既存のDOM拡張bridgeパターンを用いてプロフィールリンク列とQiitaサムネイルを補う。プロジェクトカードはサムネイルをcropせず、狭い画面では列幅を縮退させ、360px以下で縦配置へ切り替える。

受入条件は、1280pxでGitHub/X/Qiitaの3アイコンリンクが正しいURLとアクセシブルネームを持つこと、390px/320pxで全プロジェクトカードがビューポート内に収まりサムネイル全体が表示されることとする。
