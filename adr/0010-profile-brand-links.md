# ADR-0010: 公開プロフィールの外部アカウントをブランドロゴで表示する

状態: 採用

2026-09-10、利用者の明示依頼に基づき、公開プロフィールにあった `GitHub` の文字リンクをブランドロゴのリンクへ変更し、X (`@kamesaniniad`) とQiita (`@kamesan1577`) を同じ場所へ追加する。

サービスの識別は各社のブランドアセットで行い、独自の類似ロゴや自作SVGを作らない。GitHubはGitHubが配信するMark画像、Xは公式ブランドツールキットのPNG、Qiitaは公式メディアキット由来のロゴをラスタライズしたPNGを使用し、縦横比を変えない。ロゴそのものへhover変形・影・回転・縁取りを加えない。

既存の `app/notebook.tsx` の承認済み構造を大きく変更せず、既存のDOM拡張bridgeパターンを用いてプロフィールリンク列とQiitaサムネイルを補う。プロフィール欄では元の文字リンクがあった場所だけを置き換え、ロゴをカード風の枠で囲まない。

プロジェクトカードは既存の2カラム構成とカード比率を維持する。サムネイルはcropせず `contain` で全体を表示し、狭い画面では各カラムを `minmax(0, ...)` で縮退させる。320pxでもカードそのものを縦積みに変えず、既存の見た目を維持したままビューポート内へ収める。

受入条件は、1280pxでGitHub/X/Qiitaの3ロゴリンクが正しいURLとアクセシブルネームを持つこと、390px/320pxで全プロジェクトカードがビューポート内に収まりサムネイル全体が表示されることとする。
