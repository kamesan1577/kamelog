# ADR-0004: バックアップは整合性と復元まで検証する

状態: 採用

更新を止めた保守時間にDB・媒体を同じbackupディレクトリへコピーし、hash manifestで検証する。
SQLite backup APIを使いWAL内の確定済み変更を含める。
復元先は空ディレクトリのみ。既存データを上書きしない。manifest不整合・不正パスを拒否する。
定期実行はホストのschedulerへ委ね、手動操作と同じCLIを使う。日次30世代を運用初期値とする。
バックアップには非公開下書き・認証情報を含む。権限0700、オフホスト保管は暗号化を必須とし鍵は別管理する。
暗号化方式・オフホスト保存先はrunbookで運用者が設定する。公開GitやCI artifactをバックアップ先にしない。
