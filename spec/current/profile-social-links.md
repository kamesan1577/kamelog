# 公開プロフィールの外部アカウント導線

公開プロフィールの外部アカウントは、サービス名のテキストリンクではなくブランドロゴのリンクとして表示する。

- GitHub: `https://github.com/kamesan1577`
- X: `https://x.com/kamesaniniad`
- Qiita: `https://qiita.com/kamesan1577`

表示上の文字列は置かず、各リンクにはスクリーンリーダー向けのサービス名とアカウント名を付与する。外部リンクは新しいタブで開く。

ブランドアセットは各サービスのガイドラインに従い、独自の描き直し、変形、回転、影、縁取りを行わない。PR内でロゴを自作SVG化せず、GitHubとXは各社が配布・配信するブランド画像をそのまま使用する。Qiitaは公式メディアキット由来のロゴをラスタライズしたPNGを使用し、ロゴの縦横比を維持する。

プロフィール欄では既存のレイアウトを変えず、元の `GitHub` 文字リンクがあった位置にGitHub / X / Qiitaのロゴを横並びで置く。ロゴをボタン風の枠で囲わない。

プロジェクト一覧のQiitaサムネイルも同じQiitaロゴを使用する。カード自体の構成・比率は従来どおり維持し、サムネイルだけを `contain` で全体表示する。390pxの標準スマホ幅だけでなく320px相当の狭い画面でもカードをビューポート内へ収め、画像や本文が横方向にはみ出さないこと。
