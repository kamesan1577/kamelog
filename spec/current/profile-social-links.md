# 公開プロフィールの外部アカウント導線

公開プロフィールの外部アカウントは、サービス名のテキストリンクではなくブランドアイコンのリンクとして表示する。

- GitHub: `https://github.com/kamesan1577`
- X: `https://x.com/kamesaniniad`
- Qiita: `https://qiita.com/kamesan1577`

表示上の文字列は置かず、各リンクにはスクリーンリーダー向けのサービス名とアカウント名を付与する。外部リンクは新しいタブで開く。

ブランドアセットは各サービスのガイドラインに従い、変形・回転・影・独自の描き直しを行わない。Qiitaアイコンはブランドカラー `#55C500` を使用し、18px以上で表示する。アイコン周囲にアイコン幅・高さの1/2以上の余白を確保し、背景は `#3D4040` として4.5:1以上のコントラストを確保する。

プロジェクト一覧のQiitaも同じブランドアイコンを使用する。プロジェクトのサムネイルはカード比率に合わせてcropせず `contain` で全体を表示し、390pxの標準スマホ幅だけでなく320px相当の狭い画面でもカードをビューポート内へ収める。360px以下ではカードを縦配置へ切り替える。
