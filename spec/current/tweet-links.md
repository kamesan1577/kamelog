# つぶやきのリンク表示

## 表示

- つぶやき本文中の `http://` / `https://` URLはリンクとして扱う。
- 日本語の句読点や文末記号をURLへ含めず、括弧はURL内で対応が取れている場合だけ残す。
- 長いURLでも投稿幅を広げず、PC・390px相当のスマホのどちらでも本文内で折り返す。
- リンクは新しいタブで開き、投稿詳細を開く親操作へクリックを伝播させない。
- 最初のURLにOGPまたは同等のメタデータがある場合、サイト名・タイトル・説明・画像を既存の罫線主体のUIに合わせたリンクカードとして表示する。
- OGP取得失敗、メタデータなし、許可外URLの場合も本文リンクはそのまま利用できる。リンクカードの失敗を投稿表示の失敗にしない。

## OGP取得境界

- 公開 `http` / `https` の標準ポート（80/443）のみ取得する。URL内の資格情報、localhost、`.local`、loopback/private/link-local/multicast/reserved addressを拒否する。
- DNS解決結果に非公開アドレスが1件でも含まれるホストは取得しない。実HTTP接続は検証済みIPへ固定し、DNS rebindingで内部アドレスへ差し替えられないようにする。
- redirectごとにURLとDNSを再検証する。redirectは最大3回、HTMLは512KiB、1リクエスト4秒を上限にする。
- OGP画像URLも `http` / `https`・標準ポート・ローカル名/プライベートIP拒否を適用し、HTTPSページからHTTP画像へdowngradeしない。ブラウザから画像を読む場合はRefererを送らない。
- 取得結果は短時間キャッシュし、公開ページの閲覧ごとに同一URLへ無制限に再取得しない。

## 受入条件

- percent-encodeされた長いWikipedia相当URLを含むつぶやきが横にはみ出さない。
- URLをクリックするとリンク先を開け、元の投稿詳細へ誤遷移しない。
- OGPありのURLはリンクカードを表示し、OGPなし/取得失敗では本文リンクだけを表示する。
- 外部ネットワークを使わないブラウザ回帰テストでリンク化、折り返し、OGPカードを確認する。
