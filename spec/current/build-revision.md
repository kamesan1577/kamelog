# 公開サイトのビルド識別子

- ホームの既存「kamelog の開発情報」フッター末尾に、控えめな小文字で `Build · <短縮SHA>` を表示する。短縮SHAを押すと、その完全なSHAを指すGitHubのコミットページを開く。既存の項目や相互リンクの配置を変更しない。
- 表示するのはGitHubの最新commitでもホストの現在のcheckoutでもなく、現在応答しているアプリのDockerイメージをビルドしたcommitである。ビルド時にCI承認済みの40桁SHAを渡し、イメージ内の環境変数 `KAMELOG_BUILD_SHA` として固定する。blue/greenとworkerは同じイメージを使う。
- 不明・不正なSHAではリンクもラベルも出さず、別のSHAを推測して表示しない。ローカル開発時は環境変数が未設定でも正常に動作する。
- 表示時のGitHub API呼び出し・永続データ保存・追加の認証情報を必要としない。旧イメージへロールバックした場合は旧イメージのSHAが表示される。
