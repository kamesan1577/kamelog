# 現行プロダクト仕様

個人のブログ・つぶやき・短尺vlog・プロジェクトをまとめる公開サイト。
投稿者は単一オーナー。表示名・アイコン・自己紹介はアカウント画面から変更できる。

## 公開UI

既存 `app/notebook.tsx` と `app/globals.css` の外見を維持する。
インデックスはサイトの説明、公開プロフィール、ブログ・つぶやき・vlog・プロジェクトへの入口、公開投稿から選んだ人気投稿1件を表示する。タイムラインはインデックスと分離し、ホーム・コンテンツカード・ナビゲーションから移動できる。
順序はブログ・つぶやき・vlog。種別・タグ絞り込み、新しい順/いいね順、ホーム内検索、投稿詳細、URL共有、ローカルいいねを提供する。
プロジェクトはソース管理の公開リンクとして表示する。初期表示は運用者の公開プロジェクトとQiitaを案内する。
プレビューのPC/スマホ疑似切替は開発用であり本番ホームを囲まない。

## 編集

ブログはCommonMarkとGFMのMarkdown（見出し、強調、取り消し線、リスト、チェックリスト、リンク、画像、引用、コード、表、区切り線）を表示する。言語名付きコードブロックはシンタックスハイライトする。生HTMLを実行しない。
画像ファイル（PNG/JPEG/WebP/GIF、1枚12MiB以下）は本文へのドラッグ&ドロップでアップロードし、ドロップ位置へMarkdown画像リンクを挿入する。画像追加ボタンから選んだ場合は本文末尾へ挿入する。クリップボードの画像をブログ本文へ貼り付けた場合もアップロードし、カーソル位置へMarkdown画像リンクを挿入する。
ブログ・つぶやきの画像はD&D・画像追加ボタン・クリップボード貼り付けのいずれでもアップロード前にブラウザで最適化する。GIFはアニメーション維持のため元ファイルを使い、それ以外は長辺2560pxを上限としてWebP品質0.88で変換する。縮小が不要で変換後の方が大きい場合は元ファイルを使う。
`mermaid` 言語のコードブロックは図として安全に描画する。単独行のYouTube URLとX投稿URLは埋め込み表示し、その他のURLや生HTMLを実行可能な埋め込みへ変換しない。
ブログエディタは主要な記法を選択範囲へ挿入するツールバーと、対応記法を網羅したモーダルヘルプへの導線を持つ。390px相当のスマホでは記法ボタン列だけを横スクロールさせ、ヘルプとプレビュー操作は投稿モーダル内に収める。
ブログの投稿モーダルは入力内容を保ったままフルページ表示へ切り替えられる。編集、リアルタイムプレビュー、左右分割の3表示を切り替えられ、左右分割を選んだ場合は十分な幅を確保するためフルページ表示へ移る。狭い画面の左右分割は上下配置に切り替える。
ブログの初回公開日時は変更せず保持する。公開後にタイトルまたは本文を編集した場合は最終更新日時を別に保存して公開表示し、固定/解除だけでは最終更新日時を変更しない。
つぶやきとブログは明示保存する下書き。閉じる/外タップ/Escで保存・破棄・継続を選択。
投稿モーダルから既存下書きを選んで入力欄へ復元できる。開いた投稿モーダルは最初のテキスト入力欄へ自動でフォーカスする。390px相当のスマホでは投稿入力欄の文字サイズを16px以上に保ち、フォーカス時のブラウザ自動ズームを誘発しない。
PCホームのつぶやきはインラインで投稿し、ブログ・vlogはモーダルで編集する。PCの `n` は新規投稿、`Ctrl/Cmd + Enter` は投稿を実行する。
PCホームの画像添付は現在のつぶやきへ媒体を追加する操作として、ブログ・つぶやき・vlogの投稿種別選択とは別の行に配置する。
つぶやきはドラッグ&ドロップ、画像追加ボタン、クリップボード貼り付けから最大4枚を添付できる。1〜4枚を投稿内グリッドに配置し、各画像はタップ/クリックで拡大表示する。画像だけのつぶやきも投稿できる。
投稿失敗時は入力を残す。永続化成功の応答後のみ投稿済み表示へ移る。
録画は選択した長さで自動停止。既存動画も同じ選択尺で切り出し、16:9へ中央cropする。
キャプション60文字、表示時刻HH:mm。時刻は撮影開始時に自動入力する。

## 閲覧と共有

投稿詳細を開くと同一タブの履歴へ `?post=<id>` を追加する。詳細内の「戻る」とブラウザの戻る/進むはURLと表示を同期し、ホーム・プロジェクト・アカウントなど詳細外へ移動した履歴では `post` クエリを残さない。共有URLから直接開いた詳細の「戻る」はサイト外へ離脱せずホームを表示する。`post` 以外の既存クエリは詳細開閉で破棄しない。
ブログ詳細では、いいね・リンクコピー・X共有を読書中も常時操作できる追従UIとして表示する。十分な横幅がある画面では本文左側の縦型スティッキーレール、狭い画面では下部のフローティングバーとして表示し、タイムライン上の既存操作は維持する。
10秒以下のvlogは無音で自動再生し、ループする。10秒を超えるvlogは自動再生しない。自動ループは動画上のボタン1回で停止できる。
投稿の共有はリンクコピーとX共有を別の操作として提供する。
投稿URLは種別に応じた要約を含む1200x630のOGP画像を返す。ブログはタイトル、つぶやきは先頭の一文を優先し、長文は省略する。

## 技術構成と境界

Next.js / React / TypeScript、Node.js 24、SQLite、ローカル媒体、FFmpeg。
API契約: [api.md](api.md)。検証: [development.md](development.md)。SEO / 検索公開仕様: [seo.md](seo.md)。
パスキーの暗号検証は保守されたWebAuthnライブラリへ任せ、自作しない。
配布はDocker Compose。開発はホットリロード。本番はHTTPS reverse proxyの背後で動かす。
本番デプロイ可否は [deployment.md](../../runbooks/deployment.md) とHANDOFFの検証証跡で判断する。

## 対象外

一般ユーザー登録、コメント、課金、Xクロスポストは初期リリースの必須要件にしない。
バックアップ保存先の外部サービス接続、実サーバー設定は運用者の選択でありコードに埋め込まない。
