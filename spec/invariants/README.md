# 不変条件

- I01: オーナーだけが投稿・編集・下書き閲覧・アカウント設定を行える。一般登録・コメントは実装しない。
- I02: 未ログインでは通常の公開サイトに見える。小さな折り畳みログイン入口以外に管理要素を出さない。非公開データをHTML・API・キャッシュに含めない。
- I03: 承認済みUIの配置・ボタン・機能アイコン・余白を維持する。ヘッダーに模倣ロゴを足さない。UIにポエムを足さない。
- I04: 投稿種別はブログ・つぶやき・vlog。PCは既存インライン入口、スマホは右下ボタンから共通モーダル。vlog選択時だけ録画フォームを出す。
- I05: 未保存のブログ・つぶやきを外タップ・Esc・閉じる操作で無言で失わない。保存・破棄・継続を選ぶ。保存成功前にエディタを閉じない。
- I06: vlogは16:9固定、2/5/10/30秒を選択可能。時刻自動入力・一文キャプション・撮影/既存動画アップロードに対応する。
- I07: 検索はホーム内。独立検索ページを作らない。PCは右側、スマホはインライン。プロジェクトはサムネイル付き。
- I08: 投稿・下書き・プロフィール・媒体の正本はサーバーに保存する。localStorageは匿名いいねなど失ってよいUX状態だけに使う。
- I09: データは利用者のもの。整合性が検証されたバックアップから別環境へ復元できる。通常停止・更新でvolumeを削除しない。
- I10: Git・Issue・PR・CI成果物に実データ・秘密値・私的な識別情報を出さない。テストは架空fixtureを使う。
- I11: 単一ホストで運用でき、必須クラウド契約を要求しない。設定・認証鍵・実データをソースと分離する。

変更可能な方式と受入条件は `../current/`、判断理由は `../../adr/` に置く。
